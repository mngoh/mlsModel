# MLS Team Stats

An early (2023) exploratory project: scraping Major League Soccer team statistics from FBref and charting season trends, including how D.C. United performed.

The dataset in this repo (`mls_data_2010_2017.csv`, despite its name) holds 2021–2022 team passing stats. This project is archived and no longer maintained.

## Contents

- `0_data_scrape.ipynb`: scrapes season-by-season team stats from FBref
- `1_eda.ipynb`: trend graphs, scatter plots and the D.C. United analysis
- `funcs.py`: helper functions
